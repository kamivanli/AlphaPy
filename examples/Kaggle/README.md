# Kaggle Titanic Example

This mirrors the Kaggle tutorial in `docs/tutorials/kaggle.rst`.

The `input/` directory contains a small **synthetic** Titanic-shaped
dataset (same columns as the real competition data) generated locally,
since the real dataset requires a Kaggle account to download. Swap in
the real `train.csv`/`test.csv`/`gender_submission.csv` from
https://www.kaggle.com/c/titanic/data for an actual submission.

Run from this directory:

```
alphapy
```
